### 1. What is Technical SEO & The On-Page Debate
* **Core Foundation:** Technical SEO website ki buniyad (foundation) ki tarah hai. Agar technical health kharab hogi, toh kitna bhi accha content ho, search engine tak nahi pahunch payega[span_2](start_span)[span_2](end_span)[span_3](start_span)[span_3]

### 2. The Search Engine Pipeline (Crawl -> Index -> Rank)
* **Crawlability:** Googlebots dwara pages ko discover aur scan karne ke liye clean site structure, robots.txt, aur XML sitemap ka use hota hai[span_5](start_span)[span_5](end_span).
* **Indexability:** Text, code aur images ko proper meta tags aur valid HTML ke sath Google database mein store kiya jata hai[span_6](start_span)[span_6](end_span).
* **Ranking:** Fast loading speed, core web vitals, mobile responsiveness aur HTTPS security ke aadhar par SERP par rank milta hai[span_7](start_span)[span_7](end_span).
